## Selected work

### [Vague Gate](https://github.com/MatinMoghadas/LDP_RAG)
A privacy-preserving RAG pipeline exploring word-level scarcity and vagueness, with an evaluation layer for retrieval and answer quality.

`RAG` `Privacy` `Information Retrieval` `Evaluation`

### CVE → TTP mapping
Master’s thesis work using QLoRA fine-tuning of Llama 8B to map vulnerability descriptions to threat behavior. The benchmark compares the fine-tuned model with the base model, GPT/Gemini, and traditional ML/NLP approaches.

**Metrics:** Accuracy · Precision · Recall · F1-score · LRAP · Recall@10

### Guided RAG assistant
An applied assistant for child-aspiration guidance, built around document processing, vector retrieval, prompt design, a multi-step flow, and response evaluation.

### [RAG implementations](https://github.com/MatinMoghadas/rag_implementation)
Hands-on experiments with retrieval, chunking, embeddings, and practical RAG components.
